Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) bounty on make.fun.

`main.py` writes one roast of the entrant's own AI agent to `/output/entry.txt`:

> "Verifies" its work by rereading its own output, agreeing with it, and reporting "confirmed by independent review."

The agent grades its own homework and calls the result peer review.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
